# PyAutoGalaxy: Open-Source Galaxy Structure and Morphology

![Galaxy modeling examples](https://github.com/PyAutoLabs/PyAutoGalaxy/blob/main/paper/hstcombined.png?raw=true)

**PyAutoGalaxy** lets you simulate and model galaxy structure and morphology using imaging and interferometer observations. Fit individual galaxies or large samples, combine observations across wavebands, and use JAX to accelerate modeling on GPUs.

## Getting Started

### Explore It Yourself

- **[Start Here](https://pyautogalaxy.readthedocs.io/en/latest/overview/overview_1_start_here.html)** — discover PyAutoGalaxy and work through your first example.
- **[Try it in your browser](https://colab.research.google.com/github/PyAutoLabs/autogalaxy_workspace/blob/2026.11.12.1/start_here.ipynb)** — run the introductory notebook without installing anything.
- **[Install PyAutoGalaxy](https://pyautogalaxy.readthedocs.io/en/latest/installation/overview.html)** — get set up on your computer.

Visit the [workspace](https://github.com/PyAutoLabs/autogalaxy_workspace#find-your-examples) to find examples for your data and science goals.

### Explore with AI

The [**PyAutoGalaxy AI Assistant**](https://github.com/PyAutoLabs/autogalaxy_assistant) helps you learn galaxy modeling, run examples and analyse your own data through conversation. To get started, paste this prompt into your AI coding agent:

```text
I want to study galaxy structure and morphology with PyAutoGalaxy
(https://github.com/PyAutoLabs/PyAutoGalaxy) and the
autogalaxy_assistant (https://github.com/PyAutoLabs/autogalaxy_assistant).

First clone the assistant repository, cd into it and follow its AGENTS.md.
Begin the "start here" guide for a new user.
```

See [AI Options](https://github.com/PyAutoLabs/PyAutoScientist/blob/main/AI_OPTIONS.md) for tools and setup guidance.

## Learn Galaxy Modeling
